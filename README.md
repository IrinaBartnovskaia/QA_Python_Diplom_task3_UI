# UI автотесты для Stellar Burgers

Дипломный проект.  
Автотесты пользовательского интерфейса веб-приложения **Stellar Burgers**  
(Яндекс Практикум, QA Automation на Python).

---

## 📌 Описание проекта

В проекте реализованы UI-автотесты для проверки основной функциональности сайта **Stellar Burgers**:

- навигация по основным разделам;
- работа с ингредиентами;
- проверка модальных окон;
- проверка ленты заказов.

Тесты написаны с использованием **Page Object Model (POM)**, что обеспечивает:
- читаемость кода;
- переиспользование компонентов;
- простоту поддержки и расширения тестов.

---

## 🧪 Проверяемая функциональность

### Основная функциональность
- переход по клику на вкладку **«Конструктор»**;
- переход по клику на вкладку **«Лента заказов»**;
- открытие модального окна ингредиента по клику;
- закрытие модального окна по клику на крестик;
- увеличение счётчика ингредиента при добавлении в заказ.

### Лента заказов
- корректное отображение страницы ленты заказов;
- проверка работы элементов раздела.

---

## 🛠 Используемые технологии

- **Python 3.11**
- **pytest**
- **Selenium WebDriver**
- **Page Object Model (POM)**
- **Allure Report**
- **webdriver-manager**

Тесты запускаются в браузерах:
- Google Chrome
- Mozilla Firefox
